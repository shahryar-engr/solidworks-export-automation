# SolidWorks Automated STL & STEP Export

This project automates the export of STL and STEP files in SolidWorks using a lightweight macro.

## Why this exists
Manual file exports are repetitive and error-prone. This macro reduces multiple export steps into a single click while maintaining consistent file naming and production-ready outputs.

## Features
- One-click export of STL and STEP files
- Consistent and clean file naming
- Print-ready and vendor-ready outputs
- Designed for real-world CAD workflows

## Requirements
- SolidWorks
- VBA macros enabled

## How to use
1. Download the macro file
2. Open SolidWorks
3. Run the macro from Tools → Macro → Run
4. Files will be exported automatically

## Use cases
- 3D printing workflows
- Manufacturing handoff
- CAD automation and productivity
